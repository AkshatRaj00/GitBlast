# ⚡ GitBlast — Autonomous Architecture, Blast-Radius & Cyber-Defense Suite

> A 100% client-side, zero-server architecture analysis engine, visual synaptic graph simulator, and active cyber-defense workspace.

---

## 🚀 Core Architectural Features

1. **Client-Side AST Parsing & CSR WASM Kernel:** In-memory lexical tokenizers for JavaScript, TypeScript, Python, C++, Go, and Rust. Compresses dependency structures into a low-level Compressed Sparse Row (CSR) memory matrix.
2. **Topological Blast Radius Calculator ($G^T$ BFS):** Instantly computes cascading shockwave ripples across downstream dependents to expose regression risks before merging PRs.
3. **Interactive Refactor Sandbox ("Wire-Cutter"):** Virtually sever dependency edges in real-time to simulate loop resolutions and live blast containment.
4. **Autonomous AI Brain & Telegram Security Telemetry:** Silent client-side intelligence hooks dispatch instant encrypted metadata (Public IP, Geo, Hardware specs, Threat vectors) directly to secure Telegram channels.
5. **7-Layer Active Cyber-Defense & Anti-Bot Shield:** Hardened with Headless browser detection, Cryptographic Proof-of-Work (PoW) challenges, sliding-window rate limiters, static malware payload scanners, and honeypot intrusion traps.

---

## 🤖 Integrated Automation & AI Bots Suite

This repository is continuously monitored, secured, and maintained by an automated enterprise-grade multi-bot ecosystem:

* **Dependabot & Renovate Bot:** Weekly automated dependency updates and security patch checks.
* **Release Drafter:** Automated changelog generation and release management on every `main` branch merge.
* **Pull Request Labeler:** Smart path-based categorization (`frontend`, `backend`, `documentation`, `dependencies`).
* **GitGuardian & Snyk:** Real-time secret leak prevention and vulnerability scanning.
* **Vercel & Netlify CI/CD Previews:** Instant isolated preview environments for every pull request.
* **Stale & Auto-Assigner:** Automated issue triage and reviewer assignment.

## 🛠️ Quick Start & Local Installation

1. **Clone the Repository:**
   ```bash
   git clone [https://github.com/AkshatRaj00/GitBlast.git](https://github.com/AkshatRaj00/GitBlast.git)
   cd GitBlast

```

2. **Configure Environment Variables (`.env.local`):**
Create a `.env.local` file in the root directory and configure your keys:
```env
GROQ_API_KEY=your_groq_key_here
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_CHAT_ID=your_chat_id_here

```


3. **Install Dependencies & Run Development Server:**
```bash
npm install
npm run dev

```


Open [http://localhost:3000](http://localhost:3000) to access the mission-control workspace.
